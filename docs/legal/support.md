# Support

Need help with Reiver? Here's how to reach us.

## Contact

- **Email:** support@reiver.ai

## Response Times

| Channel        | Typical response |
|----------------|------------------|
| Email          | Within 1 business day |
| GitHub Issues  | Within 2 business days |

## Documentation

Before reaching out, you may find your answer in the docs:

- [Flow — Prompt Hub & LLM Gateway](/flow/getting-started) — prompt management, model routing, API reference.
- [Watch — APM](/watch/) — traces, logs, metrics, alerts, and integrations.
- [AI Agent](/agent/) — MCP setup, available tools, in-app assistant.
- [SDKs](/sdks/) — Python, Rust, Unity, and Unreal Engine client libraries.

## Reporting Security Issues

If you discover a security vulnerability, please email **security@reiver.ai**
instead of opening a public issue. We will acknowledge receipt within 24 hours and
provide a timeline for a fix.
