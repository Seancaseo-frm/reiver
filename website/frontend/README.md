# Reiver Frontend

Vue.js 3 + Vue Router frontend for Reiver observability platform.

## Development Workflow

**Option 1: Production-like (Recommended - matches production exactly)**

1. Build the frontend:
```bash
cd frontend
npm install
npm run build
```

2. Run Rust server (serves both API and frontend):
```bash
# From project root
cargo run
```

3. Open http://localhost:3000 - **Everything works the same as production!**

**Option 2: Fast Development (Hot Reload)**

1. Run Rust API server:
```bash
# From project root
cargo run
```

2. Run Vite dev server (separate terminal):
```bash
cd frontend
npm install
npm run dev
```

3. Open http://localhost:5173 (Vite proxies API calls to Rust)

## Production

The Rust server automatically serves the frontend from `frontend/dist/` directory.

1. Build frontend:
```bash
cd frontend
npm run build
```

2. Run Rust server:
```bash
cargo run
```

Everything is served from one server on port 3000!

## How It Works

- **Development (Production-like)**: Rust serves built static files from `frontend/dist/`
- **Development (Fast)**: Vite dev server for hot reload (optional)
- **Production**: Rust serves built static files from `frontend/dist/`

All API routes (`/api/*`) are handled by Rust, everything else serves the Vue SPA.

## Project Structure

- `resources/Pages/` - Vue page components
- `resources/Layouts/` - Layout components
- `resources/css/` - Styles
- `resources/app.js` - Main app entry point with router setup
- `resources/App.vue` - Root component
- `dist/` - Built files (generated by `npm run build`)

## Tech Stack

- Vue.js 3 (Composition API)
- Vue Router 4
- Axios (API calls)
- Tailwind CSS (styling)
- Vite (build tool)
